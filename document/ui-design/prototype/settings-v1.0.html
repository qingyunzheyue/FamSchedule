✓ 已加入白名单

您的设备已允许 FamSchedule 在后台运行,推送将可靠到达

为什么需要加入白名单?

国内部分 Android 厂商(如小米、华为、OPPO、vivo、三星)会默认限制应用在后台的运行,这可能导致 FamSchedule 的任务提醒无法准时到达。

加入白名单后,系统允许 App 在后台继续运行,推送通知能可靠触达。

各厂商设置路径

小米

设置 → 应用管理 → FamSchedule → 自启动 → 开启

华为

设置 → 电池 → 启动管理 → FamSchedule → 允许后台活动

OPPO

设置 → 电池 → 关闭"冻结后台不活跃应用"

vivo

设置 → 电池 → 后台高耗电 → 允许 FamSchedule

三星

设置 → 应用程序 → FamSchedule → 电池 → 不优化
