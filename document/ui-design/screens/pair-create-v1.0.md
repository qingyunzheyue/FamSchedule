# 屏幕规格:pair-create(邀请码展示页)

| 字段 | 值 |
|---|---|
| 屏幕 slug | pair-create |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-012(创建/加入家庭) |
| 关联流程图 | 流程 1 步骤 3-5 |

---

## 1. 目的

创建方 A 已创建家庭,展示 6 位邀请码 + 10 分钟倒计时,让 A 把码告诉配偶 B。

---

## 2. 触发 / 入口

- 从 pair-home 点击"创建家庭"卡片 → 调 create_family RPC 成功

---

## 3. 布局描述

```
┌────────────────────────────────────┐
│  ←                                │
│                                      │
│         邀请配偶加入                  │  ← 22px title
│                                      │
│   把这个 6 位码告诉你的配偶            │  ← 15px secondary
│   他/她打开 app 输入就能加入           │
│                                      │
│   ╭──╮╭──╮╭──╮╭──╮╭──╮╭──╮         │  ← 邀请码数字格
│   │ 4││ 8││ 2││ 9││ 1││ 7│         │     56×72px 圆角 12
│   ╰──╯╰──╯╰──╯╰──╯╰──╯╰──╯         │     36px Semibold 赤陶
│                                      │
│   ⏱  09:42 后过期       [ 复制码 ]   │  ← 倒计时 + 复制按钮
│                                      │
│   ─────────────────────────────     │
│   ✓ 配偶加入后,这里会自动显示         │  ← 等待提示
│     对方设备名                       │
│                                      │
│                                      │
│   [      我稍后邀请      ]           │  ← 次要按钮(跳过)
│                                      │
└────────────────────────────────────┘
```

- **顶部**:← 返回(回到 pair-home,但此时已创建家庭,实际是 noop)
- **邀请码数字格**:6 个独立 56×72px 圆角格,`--color-surface` 背景,数字 36px Semibold `--color-primary` 赤陶
- **数字格间距**:8px
- **倒计时**:`09:42 后过期`(分:秒,mm:ss),`⏱` icon + 13px meta
- **倒计时 ≤ 60s**:数字变 `--color-warning` 琥珀色
- **复制按钮**:chip 样式,`Copy` icon + "复制码"
- **等待提示**:`配偶加入后,这里会自动显示对方设备名`,`✓` icon(灰色,未达成)→ 配偶加入后变 success 色 + 显示配偶头像/昵称
- **底部按钮**:`我稍后邀请`(ghost 样式),点击直接跳到主 App

---

## 4. 组件分解

| 组件 | 来自 | 说明 |
|---|---|---|
| `Header` | Tamagui | ← 返回 + 标题 |
| `InviteCodeDisplay`(C-03) | 自定义 | 6 位数字格 + 倒计时 + 复制 |
| `Button` | Tamagui | "我稍后邀请" ghost |

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 创建成功 | 如上 |
| **copy-success** | 点击复制 | toast "已复制到剪贴板" + 按钮短暂 success 态(✓) |
| **countdown-low** | 倒计时 ≤ 60s | 倒计时变 warning 色,数字格也轻 warning 底色 |
| **expired** | 倒计时 = 0 | 数字格全灰 + 文案"邀请码已过期" + 主按钮变 "重新生成" + "我稍后邀请" 仍可用 |
| **spouse-joined** | Realtime 收到 family_members INSERT | 整屏淡出 + 0.5s 后跳到主 App,过渡动画 |
| **regenerating** | 点击"重新生成" | 整屏 spinner 0.5s → 新码显示 |
| **regenerate-error** | create_invite RPC 失败(罕见) | 顶部红色 banner + 倒计时继续,允许再点 |
| **network-error** | Realtime 断 | 配偶加入提示不变;reconnect 后立即同步 |

---

## 6. 内容

- **页面标题**:`邀请配偶加入`
- **副标题**:`把这个 6 位码告诉你的配偶` + `他/她打开 app 输入就能加入`
- **邀请码格式**:6 位数字,如 `482917`
- **倒计时格式**:`09:42 后过期`
- **复制按钮**:`复制码`
- **等待提示**:`配偶加入后,这里会自动显示对方设备名`
- **已加入提示**(配偶加入后):`[配偶头像] 已加入!` + `正在为你跳转到主页...`
- **过期文案**:`邀请码已过期,点击重新生成`
- **重新生成按钮**:`重新生成`
- **跳过按钮**:`我稍后邀请`
- **复制成功 toast**:`已复制到剪贴板`

---

## 7. 可访问性

- 每个数字格 `accessibilityRole="text"`,`accessibilityLabel="邀请码第 1 位,4"`
- 倒计时 `accessibilityLiveRegion="polite"`,每分钟更新一次被读屏
- 复制按钮 `accessibilityLabel="复制邀请码 482917"`
- 配偶加入后 `accessibilityLiveRegion="assertive"` + 立即 announce

---

## 8. 响应式行为

- 6 个数字格在 `≤ 360px` 屏幕缩为 48×60px,字号 32px
- 数字格间距缩为 6px

---

## 9. 出站导航

| 触发 | 跳转 |
|---|---|
| 配偶加入成功 | 主 App(任务 Tab) |
| 点击"我稍后邀请" | 主 App(任务 Tab) |
| 点击"重新生成" | 留在本页,新码覆盖旧码 |
| ← 返回 | pair-home(但实际此时已建家庭,UX 上禁用返回更佳) |

---

## 10. 微文案规范

- 邀请码用"码"不用"密码""口令",更轻
- 倒计时"后过期"而非"剩余时间",更口语
- "我稍后邀请" 给用户退出路径,不要把用户卡死在这页
- 配偶加入用 "✨ 已加入!" 感叹号增强庆祝感
