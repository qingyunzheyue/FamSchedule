# 屏幕规格:task-create(创建/编辑任务)

| 字段 | 值 |
|---|---|
| 屏幕 slug | task-create |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-001(创建) + US-003(编辑) + US-004(周期) + US-009(共同执行人) + US-010(共享) |

---

## 1. 目的

创建新任务或编辑现有任务。表单式输入,涉及标题、时间、指派人、周期、备注、共享设置。

---

## 2. 触发 / 入口

- 从 home 右上角 + 按钮
- 从 task-detail 右上角 ⋮ → 编辑
- 从 task-detail ⋮ → 复制为新任务(预填副本)

---

## 4. 组件分解

| 组件 | 来自 | 说明 |
|---|---|---|
| `Header` | Tamagui | 左 取消 / 中 标题 / 右 保存 |
| `TextInput` | Tamagui Input | 标题、备注 |
| `DatePicker` | 自定义 | chip 形式,弹底部 Sheet |
| `TimePicker` | 自定义 | chip 形式,弹底部 Sheet |
| `Chip` | Tamagui | 指派人单选、共同执行人多选 |
| `Dropdown` | Tamagui Select | 周期、共享 |
| `Sheet` | Tamagui Sheet | DatePicker、TimePicker、共同执行人选择 |
| `Button`(底部删除) | Tamagui | error 文字按钮(仅编辑模式) |

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 默认 | 如 3.1 |
| **empty** | 标题未填 | 标题框红色描边 + "标题不能为空" |
| **saving** | 点击保存 | 保存按钮变 spinner + "保存中..." |
| **save-success** | 保存成功 | 自动关闭页面,回 home,toast "已创建 ✨" |
| **save-error** | 保存失败 | toast "保存失败,请重试" + 按钮恢复 |
| **editing-template** | 编辑周期任务 | 顶部黄色提示 banner |
| **deleting-confirm** | 编辑模式点击删除 | Dialog 二次确认 |
| **validation-error** | 必填项未填 | 主按钮 disabled + 字段红色描边 |

## 6. 内容

### Header
- 创建:`取消  新建任务  保存`
- 编辑:`取消  编辑任务  保存`

### 字段 label
- `任务标题 *`(必填)
- `日期 *`(必填)
- `时间`(可选)
- `指派人 *`(必填,默认"我")
- `共同执行人`(可选)
- `周期`(可选,默认"不重复")
- `备注`(可选)
- `共享`(可选,默认"私有")

### 周期选项
- `不重复`(默认)
- `每日`
- `每周(选星期几)`
- `每月(选几号)`
- 二级:星期 chips(`一 二 三 四 五 六 日`,多选) / 月份 chip(`1-31`,单选)

### 共享选项
- `🔒 私有(仅我可见)`(默认)
- `👁 共享给配偶查看(只读)`
- `👥 共享给配偶执行(可打卡)`

### 备注占位
- 创建:`给任务加点提醒...`
- 喂奶粉示例:`7 勺奶粉,150ml 温水`
- 保险示例:`记得带身份证和保单号`

### 占位任务标题(常用预设)
- `喂奶粉` / `续交保险单` / `倒垃圾` / `提醒吃药` / `整理衣物` / `给车加油` / `洗碗` / `辅导孩子作业` / `买菜`

### 错误文案
- 标题空:`标题不能为空`
- 保存失败:`保存失败,请重试`
- 网络异常:`网络异常,稍后重试`

### 周期任务编辑提示
- `修改会同步到所有未来的重复实例`
- `本次修改不影响已完成的实例`

### 删除 Dialog(编辑模式)
- 标题:`删除这个任务?`
- 内容:分两种文案:
  - 一次性任务:`任务"喂奶粉"将被删除,无法恢复。`
  - 周期任务:`任务"喂奶粉"是周期任务。可选择"仅删除这一实例"或"删除整个系列"。`
  - 三个按钮:`仅这一实例` / `整个系列` / `取消`

## 7. 可访问性

- 必填项 `accessibilityHint="必填"`
- DatePicker / TimePicker `accessibilityRole="button"`,label 含当前值
- 指派人 chips `accessibilityRole="radio"`,当前 `accessibilityState={{selected: true}}`
- 共同执行人 chips `accessibilityRole="checkbox"`
- 周期 / 共享 `accessibilityRole="combobox"`
- 保存按钮 disabled 时 `accessibilityState={{disabled: true}}` + label "请先填写必填项"

---

## 8. 响应式行为

- 主流手机 375-414px:如上
- 平板(> 600px):表单最大 640px 居中
- 键盘弹起:页面整体上移,确保当前焦点字段 + 保存按钮可见

## 10. 微文案规范

- "任务标题" 而非 "任务名",更符合日常用法
- "指派人" 而非 "负责人",更符合家庭分工语境
- "共同执行人" 而非 "参与者",更明确任务性质
- 共享三档用 icon 区分:🔒 私有 / 👁 查看 / 👥 执行
- 周期说明简洁:"每日" 不用 "每天重复";"每周一、三、五" 不用 "每周的第 1、3、5 天"
- 备注 placeholder 用场景化示例(喂奶粉 / 保险)而非"请输入备注"
- 删除二次确认:周期任务提供"仅这一实例"和"整个系列"两选项,避免误操作
