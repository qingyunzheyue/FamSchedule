# 屏幕规格:pair-home(配对主页)

| 字段 | 值 |
|---|---|
| 屏幕 slug | pair-home |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-012(创建/加入家庭) |
| 关联流程图 | 流程 1 步骤 1-2(创建方) / 步骤 4-5(加入方) |

---

## 1. 目的

用户首次启动后,无 family_id,需要选择"创建家庭"或"加入配偶的家庭"。是所有家庭协作的**唯一入口点**。

---

## 2. 触发 / 入口

- 启动后 splash 检测到无 family_id
- 之前配对过但因 token 失效重置(401 错误恢复场景,极少)

---

## 3. 布局描述

```
┌────────────────────────────────────┐
│         状态栏(系统)                │
│                                      │
│         欢迎来到 FamSchedule         │  ← 22px Semibold
│                                      │
│   选择一个方式,开始你们的家庭日程    │  ← 15px secondary
│                                      │
│   ╭──────────────────────────────╮  │
│   │ ⊕   创建家庭                  │  │  ← 大卡片,可点击
│   │     生成邀请码,邀请配偶加入    │  │     16px meta 描述
│   ╰──────────────────────────────╯  │
│                                      │
│   ╭──────────────────────────────╮  │
│   │ ✉   加入家庭                  │  │
│   │     输入配偶给你的 6 位邀请码   │  │
│   ╰──────────────────────────────╯  │
│                                      │
│                                      │
│  我们不会收集任何个人信息              │  ← 11px micro tertiary
│  只用一个匿名设备 ID                  │
│                                      │
└────────────────────────────────────┘
```

- **背景**:`--color-background`
- **顶部文案**:22px Semibold `欢迎来到 FamSchedule` + 15px secondary `选择一个方式,开始你们的家庭日程`
- **两个卡片**:垂直间距 16px,圆角 14px,elevation-1 软阴影
  - 卡片 padding 16-20px
  - 左侧 32×32px icon(Phosphor `Plus` / `EnvelopeOpen`)
  - 标题 17px Medium
  - 描述 13px Regular secondary
- **底部隐私说明**:11px micro,tertiary 灰

---

## 4. 组件分解

| 组件 | 来自 | 说明 |
|---|---|---|
| `Text` × 3 | Tamagui | 标题、描述、隐私 |
| `Card` × 2 | 自定义 `ActionCard` | 大型可点击卡片,wrap `Pressable` |
| `Icon` × 2 | Phosphor | `Plus`(创建)/ `EnvelopeOpen`(加入) |

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 默认 | 如上 |
| **already-in-family** | RLS 隐式:user 已在 family 中 | 两卡片均 disable,显示"你已在 [家庭名] 中"(理论上不应出现,兜底) |
| **network-error** | 创建/加入 RPC 失败 | 顶部红色 banner(非阻塞),卡片可继续点 |
| **loading** | 创建中 | "创建家庭" 卡片整体 spinner + 文案"创建中..." |

---

## 6. 内容

- **标题**:`欢迎来到 FamSchedule`
- **副标题**:`选择一个方式,开始你们的家庭日程`
- **创建卡片**:
  - 标题:`创建家庭`
  - 描述:`生成邀请码,邀请配偶加入`
- **加入卡片**:
  - 标题:`加入家庭`
  - 描述:`输入配偶给你的 6 位邀请码`
- **隐私说明**:`我们不会收集任何个人信息,只用一个匿名设备 ID`

---

## 7. 可访问性

- 两卡片 `accessibilityRole="button"`,分别有 `accessibilityLabel="创建家庭,生成邀请码,邀请配偶加入"`
- 隐私说明 `accessibilityRole="text"`,不被读屏跳过

---

## 8. 响应式行为

- 卡片占满宽度(`--space-4` 边距)
- 小屏:`< 360px` 卡片 padding 缩至 14px

---

## 9. 出站导航

| 点击 | 跳转 |
|---|---|
| 创建家庭卡片 | pair-create(邀请码展示页) |
| 加入家庭卡片 | pair-join(输入邀请码页) |
| 隐私说明(如有链接) | 隐私详情页(About 下的 Privacy) |

---

## 10. 微文案规范

- 不用"注册""登录"等词(无账号体系)
- "6 位邀请码" 让用户预期明确
- 隐私说明放在底部小字,既不抢眼又让用户知道我们重视隐私
