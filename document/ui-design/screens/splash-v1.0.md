# 屏幕规格:splash(启动页)

| 字段 | 值 |
|---|---|
| 屏幕 slug | splash |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-013(匿名身份初始化)+ T-SETUP-9(导航骨架) |
| 关联流程图 | 流程 1 步骤 1-2(首次匿名登录) |

---

## 1. 目的(Purpose)

用户首次启动 / 冷启动进入 App 时展示的过渡页。承载三个动作:
1. Anon Sign-in(Supabase 自动匿名登录)
2. 检查本地是否已有 family_id(决定跳到 Pair Home 还是主 App)
3. 拉取本地通知权限(US-007 必需)

启动时长 < 1s,期间展示品牌视觉,安抚等待。

---

## 2. 触发 / 入口

- **冷启动**:App 进程被系统杀死后再次打开
- **首启**:从未安装过的设备
- **进程重启**:`onAuthStateChange` 触发 token refresh 失败时,也会回到 splash

---

## 3. 布局描述

```
┌────────────────────────────────────┐
│         状态栏(系统)                │
│                                      │
│                                      │
│         ╭───────╮                   │
│         │ 🏠  12 │                  │  ← Logo:赤陶色房子 + 日历格子
│         ╰───────╯                   │     96×96px
│                                      │
│         FamSchedule                 │  ← 品牌名 22px Semibold
│         家里的小日程                │  ← 标语 13px Regular secondary
│                                      │
│         (启动 < 1s,无进度条)         │
│                                      │
└────────────────────────────────────┘
```

- **背景**:`--color-background` `#F4ECDC` 亚麻(亮色)/ `--color-background` `#1A1814` 深棕黑(暗色)
- **Logo**:赤陶色 `#DC5A24`,96×96px,居中
- **品牌名**:"FamSchedule",22px Semibold,`--color-text-primary`
- **标语**:"家里的小日程",13px Regular,`--color-text-secondary`
- **垂直位置**:Logo + 文字组合在屏幕中点偏上(40% 位置)
- **底部安全区**:48px

| 组件 | 来自 | 说明 |
|---|---|---|
| `Logo` | 自定义 | 房子+日历格子 SVG,赤陶色 |
| `Text`(品牌名) | Tamagui | 22px Semibold |
| `Text`(标语) | Tamagui | 13px Regular |

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 默认 | 如上布局 |
| **error** | Anon Sign-in 失败且重试 1 次仍失败 | 居中错误占位:⚠ icon + "无法连接到服务器" + 重试按钮(详见档 1 阻塞性错误) |
| **offline** | 网络断开 | 启动期间不显示额外提示(本身 < 1s);若 > 2s 未完成,显示"连接中..."小字 |

---

## 6. 内容

- **品牌名**:`FamSchedule`(英文,稳定;不在 v1 国际化范围)
- **标语**:`家里的小日程`
- **错误文案**:`无法连接到服务器,请检查网络后重试`
- **重试按钮**:`重试`
- **网络延迟文案**:`连接中...`

---

## 7. 可访问性

- 整屏标记为 `accessibilityRole="progressbar"`,screen reader 播报"FamSchedule 正在启动"
- 错误态:`accessibilityRole="alert"`,错误信息被立即播报
- Logo:`accessibilityLabel="FamSchedule logo"`
- 暗色模式:自动跟随系统

---

## 8. 响应式行为

- **手机竖屏**(主要,375-414px):如上
- **手机横屏 / 平板**:Logo 上移,文字组保持垂直居中
- **小屏**(≤ 320px):Logo 缩至 72×72,字体 18/12

---

## 9. 出站导航

| 状态 | 跳转目标 |
|---|---|
| Anon 成功 + 无 family_id | pair-home(配对主页) |
| Anon 成功 + 有 family_id | home(任务 Tab) |
| Anon 失败 | 阻塞性错误占位 → 重试 |

---

## 10. 微文案规范

- **品牌名**:不在屏幕内做 i18n 切换,保持英文
- **标语**:用「家里的小日程」而非「家庭日程管理」,更口语更温度
- **错误文案**:`无法连接到服务器` 而非 `网络异常`,更人话
