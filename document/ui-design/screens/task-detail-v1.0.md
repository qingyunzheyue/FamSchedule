# 屏幕规格:task-detail(任务详情页)

| 字段 | 值 |
|---|---|
| 屏幕 slug | task-detail |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-002(查看) + US-003(编辑/删除) + US-005(打卡) + US-006(补卡) + US-014(过期) + US-009/010(共享) |
| 关联流程图 | 流程 2(打卡并发) |

---

## 1. 目的

展示单个任务的完整信息:标题、时间、指派人、共同执行人、共享状态、打卡历史、补卡入口。提供"打卡"主操作 + "编辑/删除"次操作。

---

## 2. 触发 / 入口

- 从 home 的 TaskCard 点击
- 通知点击(带 `data.taskId`)

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 未过期未完成 | 如 3.1 |
| **overdue** | task_time < now AND not completed | 顶部 banner + 打卡按钮变 "补卡" |
| **overdue-cannot-makeup** | 已过 late_checkin_cutoff | 打卡按钮变 "已截止" disabled |
| **completed** | completed_at IS NOT NULL | 大字 success + 撤销按钮(5 分钟) |
| **completed-no-undo** | 完成 > 5 分钟 | 撤销按钮消失,仅显示完成信息 |
| **cancelled** | cancelled = true | 整页轻度灰,主操作区显示"已取消" |
| **loading** | 首次拉取 | 骨架屏 |
| **error** | RPC 失败 | 居中错误占位 + 重试 |
| **editing** | 点击编辑 | 跳到 task-create(预填) |
| **deleting-confirm** | 点击删除 | Dialog 二次确认 |

## 6. 内容

### Header
- 标题:`任务详情`
- 更多菜单:`编辑` / `删除` / `复制为新任务`

### 任务区
- 标题:`喂奶粉` / `续交保险单` / `倒垃圾` 等
- 时间行:`10:00 · 今天` / `全天 · 9 月 10 日` / `明天 10:00`
- 打卡按钮:`✓ 打卡` / `✓ 补卡` / `已截止`
- 已完成:`✓ 已完成` + `10:05 由 小张 完成`
- 撤销按钮:`↶ 撤销打卡 (4:32)`(mm:ss 倒计时,5:00 → 0:00)
- 过期 banner:`⚠ 此任务已过期 14 小时` + `补卡` 链接

### 分组
- `备注`(可选)
- `指派人`
- `共同执行人`(可选)
- `共享设置`(可选)
- `周期`(可选)
- `打卡历史`

### 身份
- `👤 我(小张)` / `👤 配偶(小李)` — 实际 MVP 不显示"小张/小李"小名(因为无真实账号),用 Identity A/B 标签
- v1 简化为:`👤 我` / `👤 配偶`

### 备注示例
- `7 勺奶粉,150ml 温水`
- `记得带身份证`
- `用孩子的小书包`

### 共享
- `🌍 共享给配偶查看`(无打卡)
- `🌍 共享给配偶执行`(可打卡)

### 周期
- `每日`
- `每周一、三、五`
- `每月 12 号`

### 打卡历史
- `✓ 10:05  小张`
- `✓ 昨天 10:02  小李(补卡)`

### 删除确认 Dialog
- 标题:`删除这个任务?`
- 内容:`任务"喂奶粉"将被删除,无法恢复。`
- 主按钮:`删除`(error 色)
- 次按钮:`取消`

### 编辑二次确认(对未完成模板任务)
- Dialog:`修改这个任务,会影响未来的所有重复实例`
- 主按钮:`确认修改`
- 次按钮:`取消`

## 7. 可访问性

- 任务标题 `accessibilityRole="header"`
- 打卡按钮 `accessibilityRole="button"`,label 包含完整状态(打卡/补卡/已截止/已撤销等)
- 撤销按钮 label 包含倒计时信息
- 过期 banner `accessibilityRole="alert"`
- 打卡历史 `accessibilityRole="list"`,每条记录 `role="listitem"`
- 共同执行人头像 `accessibilityLabel="配偶"`
- 共享/周期等分组 `accessibilityRole="summary"`

## 8. 响应式行为

- 主流手机 375-414px:如上,左右内边距 16px
- 平板(> 600px):内容区最大 640px 居中
- 暗色模式:success 区块用深绿底;过期 banner 用深琥珀

## 9. 出站导航

| 触发 | 跳转 |
|---|---|
| ← 返回 | home(列表会刷新) |
| 打卡/补卡 | 留在本页,状态切换 |
| 撤销 | 留在本页,状态切回 default |
| 编辑 | task-create(预填) |
| 删除 | 删除后回 home,toast "已删除" |
| 复制为新任务 | task-create(预填副本) |
| 通知点入 | 来自通知时,返回栈是 home → task-detail |

---

## 10. 微文案规范

- 补卡 vs 打卡:用同一个按钮,文案根据状态切换
- "由小张完成" 而非"小张已完成"(更顺)
- 备注区如果有,显示完整内容(无省略)
- "已截止" 比 "无法补卡" 更明确说明原因
- 删除用"删除"不用"移除",但文案解释"无法恢复"以防误操作
- 复制为新任务:避免用户每次手动输入相似任务
