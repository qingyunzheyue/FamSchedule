# 屏幕规格:home(任务列表首页)

| 字段 | 值 |
|---|---|
| 屏幕 slug | home |
| 文档版本 | v1.0 |
| 状态 | ✅ Done |
| 关联用户故事 | US-002(任务列表) + US-014(过期标记) + US-015(过期 banner) + US-005(打卡) + US-009/010(共享/共同执行人) |
| 关联流程图 | 流程 2(打卡并发)+ 流程 5(过期 banner) |

---

## 1. 目的

用户每天打开 5-15 次的核心页。展示"今天/本周/全部"3 个视图的任务列表,提供过期 banner、独立打卡入口、指派人/共同执行人/共享等元信息。

---

## 2. 触发 / 入口

- App 主 Tab "任务" 默认页
- 任何操作(打卡/编辑/创建)完成后返回

---

## 3. 布局描述

### 3.1 整体结构

│ ⚠ 你有 2 个任务过期未完成   查看 →   │  ← 过期 banner(N=0 时消失)
│ ─────────────────────────────────── │
│ [ 今天 ]  本周   全部                │  ← Segmented tab
│ ─────────────────────────────────── │
│                                      │

### 3.2 Header 详细

- **左**:`早安,9 月 10 日 周三` 文案组
  - "早安" 13px Regular `--color-text-secondary`(根据时段自动切换:5-11 早安,12-17 下午好,18-22 晚上好,23-4 夜深了)
  - "9 月 10 日 周三" 22px Semibold `--color-text-primary`
- **右**:我头像(FamilyAvatarStack 风格,32px)+ 右上角 + 按钮
  - 头像 tap → 我的个人页(本期未做,本期 noop)
  - + 按钮 → 创建任务页(task-create)

### 3.3 过期 banner(OverdueBanner, C-04)

- 整条 12px 圆角,warning 浅色背景,warning 文字色
- 左 ⚠ icon,中文案 `你有 N 个任务过期未完成`,右 `查看 →` 链接
- 整条可点击 → 切换 segmented tab 到 "全部" + 过滤 expired = true
- N=0 时**完全消失**(不留空占位)
- N>1 时文案 `你有 2 个任务过期未完成`(用阿拉伯数字)

### 3.4 Segmented tab(US-002)

- 3 个 tab:`今天` `本周` `全部`
- 当前 tab 文字 + 底部 2px `--color-primary` 横线
- 未选中 tab:文字 `--color-text-secondary`
- 高度 48px,字号 15px Medium

### 3.5 TaskCard(C-01)详细

```
╭──────────────────────────────────╮
│ 10:00  喂奶粉           [○ 打卡]  │  ← 时间 + 标题 + 打卡圆圈
│        👤 配偶 · 👥 共同执行       │  ← meta 行
╰──────────────────────────────────╯
```

- **圆角** 14px,内边距 16px,elevation-1 软阴影,surface 背景
- **卡片间距** 12px(垂直),列表左右各 `--space-4`
- **左侧时间**:`10:00` 17px Medium(`--color-text-primary`)
- **中间标题**:`喂奶粉` 17px Medium,最多 1 行省略
- **右侧打卡圆圈** 36px,圆角 full,fill 状态 success 色
- **Meta 行**(下方):13px meta secondary
  - 指派人:`👤` 头像 16px + 文字(`我` / `配偶`)
  - 共同执行:`👥` icon + `共同执行`
  - 周期:`🔁` icon + `每日` / `每周三` / `每月 12 号`
  - 共享:`共享给配偶`
- **状态变体**:
  - **已完成**:整卡 opacity 0.55,标题加删除线,打卡圆圈 fill success,圆圈旁显示"✓ 已完成"或打卡时间
  - **已过期**:左侧 4px 竖条 `--color-warning`,背景轻 warning 底色,标题旁有"⚠ 已过期"标签
  - **已取消**:整卡 opacity 0.4,标题删除线
  - **共享查看**(US-010):打卡圆圈位置变 👁 眼睛 icon(disabled)
- **点击卡片** → 任务详情页(task-detail)

### 3.6 空状态

- "今天" 无任务时:居中 ☕ 咖啡杯插画 + "今天没有任务" + "享受一下空闲 ☀️" + 主按钮"创建任务"
- "本周" 无任务时:类似,文案改为"本周还没有任务"
- "全部" 无任务时:"还没有任何任务,创建第一个吧" + 主按钮

### 3.7 加载状态

- 首次拉取:6 个 SkeletonCard(真实布局骨架)
- 下拉刷新:顶部 16-20px spinner,赤陶色
- 操作反馈(打卡/编辑):乐观 UI,无 spinner

### 3.8 错误状态

- 网络断:顶部 16-24px 琥珀色离线 banner(OfflineBanner)
- RPC 失败:顶部红色 banner + toast
- 数据为空 + 网络错:骨架屏变红色错误占位

## 6. 内容

### Header 文案
- 时段问候:`早安` / `下午好` / `晚上好` / `夜深了`
- 日期:`9 月 10 日 周三`(中文格式,自动计算星期)

### 过期 banner
- 文案:`你有 2 个任务过期未完成`
- 链接:`查看 →`

### Segmented tab
- `今天` / `本周` / `全部`

### TaskCard 文案
- 时间:`10:00` / `全天`(无时间)/ `明天 10:00`
- 标题:`喂奶粉` / `续交保险单` / `倒垃圾` / `提醒吃药` / `整理衣物` / `给车加油` / `洗碗` / `辅导孩子作业`
- Meta:
  - `👤 我` / `👤 配偶`
  - `👥 共同执行`
  - `🔁 每日` / `每周三` / `每月 12 号`
  - `共享给配偶`
- 状态:`⚠ 已过期` / `✓ 已完成 10:05` / `已取消`

### 空状态
- `今天没有任务`
- `享受一下空闲 ☀️`
- `本周还没有任务`
- `还没有任何任务,创建第一个吧`

## 7. 可访问性

- Header 时段问候 + 日期 `accessibilityRole="header"`
- Segmented tab `accessibilityRole="tablist"`,每个 tab `role="tab"`,当前 `accessibilityState={{selected: true}}`
- TaskCard 整卡 `accessibilityRole="button"`,label 包含:标题、时间、指派人、状态、是否过期/已完成
- 打卡圆圈 `accessibilityRole="button"`,label `打卡:喂奶粉,10:00`;已打卡态 label `已完成,点击撤销`
- 过期 banner `accessibilityRole="button"`,label `你有 2 个任务过期未完成,点击查看`
- 屏幕阅读器列表遍历时,自动读出每个 task

## 8. 响应式行为

- 主流手机 375-414px:如上
- 平板(> 600px):列表最大宽度 640px 居中,左右留白
- 暗色模式:surface 变深棕黑,所有文字反色,打卡圆圈在暗色下用 success 浅色变体

## 10. 微文案规范

- 时段问候用"早安/下午好"等口语,不用"早上好/下午好"
- "今天没有任务" 比 "暂无任务" 更有温度
- Meta 行"·"分隔符(中文点号),不用"|"
- 数字用阿拉伯数字:`2 个任务`,不用"两个"
- 任务标题假定为短标题(2-8 字),列表中最多 1 行省略
- 已完成时间显示完整"10:05"而非"5 分钟前",避免计时刷新造成 UI 抖动
