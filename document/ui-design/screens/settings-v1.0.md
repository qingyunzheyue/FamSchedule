## 5. 状态

### 主页
| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 默认 | 如 3.1 |
| **whitelist-detecting** | 点击"重新检测" | 状态卡 spinner + "检测中..." |
| **whitelist-changed** | 检测结果变化 | 顶部 toast + 状态卡更新 |

### 二级页(各页通用)
| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 正常 | 如上 |
| **saving** | 改设置项 | 立即乐观更新,后台 RPC 失败时 toast |
| **save-failed** | RPC 失败 | 顶部红色 banner + 回滚 |
| **loading** | 首次拉取 | 骨架屏 |

### 反馈表单
| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 初始 | 表单空 |
| **submitting** | 提交中 | 按钮 spinner + "提交中..." |
| **success** | 提交成功 | toast "已收到,感谢反馈 ☕" + 表单清空 + 留在页 |
| **error** | 提交失败 | toast "网络异常,稍后重试" + 保留表单 |
| **empty-content** | 描述空 | 提交按钮 disabled |

## 7. 可访问性

- 设置主页 `accessibilityRole="list"`,每行 `role="listitem"` + `accessibilityHint="点击进入二级页"`
- 时段 chips `accessibilityRole="radio"`
- 反馈类型 chips `accessibilityRole="radio"`
- 单选 RadioGroup `accessibilityRole="radiogroup"`
- 状态卡 `accessibilityRole="status"`
- 提交按钮 disabled 时 `accessibilityState={{disabled: true}}`

## 10. 微文案规范

- 不用"配置"用"设置",更口语
- 描述用"做什么"不用"是什么"(`选择每天早上几点发送今日任务概览` 而非 `每日早汇总时间`)
- 厂商引导用箭头 → 而非顿号,视觉清晰
- 时段选择用 24h 制,符合国内习惯
- 默认值用"(默认)"小标,不另起一行
- 反馈类型 chips 4 个选项精简,不开放自由文本类型
- 联系页用"开发者"不用"客服",符合"内部产品"调性
- 隐私说明**第一句就要诚实**:"我们使用 Supabase Anon Sign-in,首次启动自动生成匿名设备 ID"——不绕弯子
