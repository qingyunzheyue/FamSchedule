---

## 1. 目的

家庭 Tab 的主页。展示家庭关系(成员)、邀请码入口、双方今日完成度、共享任务。提供"邀请配偶"快捷入口,让用户在任何时候都能"重新邀请"(如配偶卸载重装后)。

---

## 2. 触发 / 入口

- 底部 Tab Bar 第二个 tab "家庭"

## 4. 组件分解

| 组件 | 来自 | 说明 |
|---|---|---|
| `FamilyMemberCard` | 自定义 | 家庭成员卡(含邀请码) |
| `FamilyAvatarStack`(C-05) | 自定义 | 双头像 |
| `InviteCodeDisplay`(C-03) | 自定义 | 6 位数字 + 倒计时 + 复制 |
| `CompletionProgress` | 自定义 | 横向进度条 + 数字 |
| `SharedTaskItem` | 自定义 | 共享任务列表项(轻量,非完整 TaskCard) |
| `FamilyBoardStats` | 自定义 | 本周完成统计 + 连续天数 |

---

## 5. 状态

| 状态 | 触发 | 视觉 |
|---|---|---|
| **default** | 配对完成,正常 | 如上 |
| **no-invite** | 配偶已加入,无邀请码 | 成员卡只有 2 个头像,无邀请码区域 |
| **invite-active** | 邀请码有效 | 邀请码区域显示码 + 倒计时 |
| **invite-low** | 倒计时 ≤ 60s | 倒计时变 warning 色 |
| **invite-expired** | 邀请码已过期 | 邀请码区域变灰 + "重新生成"按钮 |
| **empty-shared** | 没有共享任务 | "还没有共享任务,在任务编辑里开启共享" 引导 |
| **loading** | 首次拉取 | 骨架屏 |
| **regenerating** | 点击"重新生成" | 邀请码区 spinner 0.5s |
| **network-error** | 网络断 | 顶部红色 banner |

## 6. 内容

### 区块标题
- `我的家庭`
- `今日家庭完成度`
- `共享任务 (5)`
- `家庭公开看板`

### 家庭成员卡
- 标题:`👤 我` / `👤 配偶`(配偶名可选,v1 简化为"配偶")
- 加入时间:`加入于 9 月 1 日`
- 配偶未加入时:配偶行显示 "等待配偶加入..." + "邀请配偶" 按钮
- 按钮:`邀请配偶` / `重新生成码` / `复制码`
- 邀请码区域:`邀请码 482917` + `⏱ 09:42 后过期` + `[ 复制码 ]`

### 完成度
- `我 ████████░░ 4/6 67%`
- `配偶 ██████░░░░ 3/6 50%`
- `今日合计 ████████░░ 7/12 58%`

### 共享任务
- 标题:`医保卡续费` / `周末大扫除` / `买尿布` / `倒垃圾` / `辅导孩子作业`
- 元信息:`9 月 15 日 · 共享给配偶查看` / `周六 10:00 · 配偶 + 我`
- 共享 icon:`👁 查看` / `👥 执行`

### 家庭公开看板
- `本周完成统计`
- `连续打卡: 我 5 天,配偶 3 天`
- "查看详情" 链接(本期不展开,后续 P1 阶段)

### 空状态
- 共享任务为空:`还没有共享任务` + `在任务编辑页开启共享`
- 看板数据为 0:`本周还没有完成任务`

### 错误文案
- 复制成功 toast:`已复制到剪贴板`
- 重新生成失败 toast:`生成失败,请重试`
- 网络异常:`网络异常,稍后重试`

## 7. 可访问性

- 家庭成员卡 `accessibilityRole="region"`,label "家庭成员"
- 邀请码 6 个数字格 `accessibilityRole="text"`
- 倒计时 `accessibilityLiveRegion="polite"`
- 进度条 `accessibilityRole="progressbar"`,label "我的今日完成度 4/6,67%"
- 共享任务 `accessibilityRole="list"`,每项 `role="listitem"`

## 10. 微文案规范

- "我的家庭" 而非 "家庭管理",前者更有"家"的感觉
- 完成度用具体数字 `4/6 67%`,不用 "大部分"
- 共享任务用 👁 / 👥 区分查看 vs 执行,一目了然
- "家庭公开看板" 而非 "家庭数据",更温度
- 连续打卡天数:用"天"不用"次",符合中文习惯
- 配偶显示 `👤 配偶`(v1 简版),P1 阶段可自定义昵称
